1//! Embedded fallback font — standalone binary variant, no system font
2//! database required at runtime.
3//!
4//! `plotters`' default feature set (`ttf`) resolves font family names like
5//! `"sans-serif"` via `font-kit`, which on Linux goes through `fontconfig`/
6//! `freetype` — real dynamic-library dependencies at *runtime*, not just at
7//! build time (confirmed via `cargo tree -e normal -i font-kit`: `chrom-rs
8//! → plotters → font-kit`, not a `criterion`/dev-only artifact). For a
9//! "download and run" distributable binary, that's a dependency the target
10//! machine may not have installed.
11//!
12//! This crate instead builds `plotters` with the `ab_glyph` feature — a
13//! pure-Rust font renderer with zero system dependency — and embeds one
14//! specific font directly into the compiled binary via `include_bytes!`.
15//! The trade-off: `ab_glyph` has no name-based system font *discovery* the
16//! way `fontconfig` does, so every family name a chart uses (this crate
17//! only ever uses `"sans-serif"`) must be explicitly registered with the
18//! embedded font's bytes before any chart is rendered — every public
19//! `plot_*` function in this crate does that itself, on entry, guarded by
20//! `std::sync::Once` so it's cheap after the first call; see
21//! [`register_fonts`] for why this isn't left to callers to remember.
22//!
23//! # Font and license
24//!
25//! [DejaVu Sans](https://dejavu-fonts.github.io/), Regular weight only —
26//! the Bitstream Vera Fonts license (see `assets/fonts/LICENSE-DEJAVU.txt`) permits
27//! embedding and redistribution in compiled form; the only restriction is
28//! that a *modified* font can't keep the "Bitstream"/"Vera" names, which
29//! doesn't apply here since the font is embedded unmodified.
30//!
31//! Only the `Normal` style is registered. `plotters` falls back to
32//! `FontStyle::Normal` for any unregistered style under the same family
33//! name (see `plotters`' `ab_glyph` backend, `FontMap::get_fallback`), so
34//! there's no need to bundle a Bold/Oblique variant unless a chart actually
35//! requests one — none does today.
36
37use std::sync::Once;
38
39use plotters::style::{FontStyle, register_font};
40
41/// DejaVu Sans, Regular — embedded so `"sans-serif"` resolves without a
42/// system font database. See the module-level doc comment for the license.
43static DEJAVU_SANS: &[u8] = include_bytes!("../../../assets/fonts/DejaVuSans.ttf");
44
45/// Guards the actual registration so it only runs once per process, no
46/// matter how many call sites invoke [`register_fonts`] — see that
47/// function's doc comment.
48static REGISTER_ONCE: Once = Once::new();
49
50/// Registers the embedded font under the `"sans-serif"` family — the name
51/// every chart in this crate uses via `.into_font()`.
52///
53/// Every public `plot_*` function in this crate calls this at its own
54/// entry point, so callers never *need* to call it themselves — including
55/// `#[test]` functions that call `plot_chromatogram` and friends directly,
56/// which is exactly the case that broke before this used `std::sync::Once`
57/// (see the module-level doc comment: `main()` in `src/main.rs` and the
58/// `tools/plot_*.rs` binaries called this explicitly, but the test suite
59/// calls the plotting functions directly and never went through `main()`
60/// at all, so `"sans-serif"` was never registered — `FontError::FontUnavailable`
61/// at test time). Calling it explicitly at the top of `main()` as well is
62/// harmless — `std::sync::Once` makes every call after the first a no-op —
63/// and left in place there mainly as documentation of intent.
64///
65/// # Panics
66///
67/// Panics (on the first call only) if the embedded font bytes fail to
68/// parse as a valid TrueType font. This can only happen if
69/// `assets/fonts/DejaVuSans.ttf` is replaced with an invalid file — the
70/// bytes are fixed at compile time via `include_bytes!`, so this is a
71/// build-time invariant, not a runtime condition that depends on anything
72/// the caller controls.
73pub fn register_fonts() {
74    REGISTER_ONCE.call_once(|| {
75        if register_font("sans-serif", FontStyle::Normal, DEJAVU_SANS).is_err() {
76            panic!(
77                "embedded assets/fonts/DejaVuSans.ttf is not a valid TTF — this should never fail"
78            );
79        }
80    });
81}
